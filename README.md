# InterviewAI

> AI-Powered Mock Interview Platform built with Spring Boot, React, TypeScript, PostgreSQL, Docker and OpenAI.

## Project Overview

InterviewAI is an industry-grade AI mock interview platform that helps students prepare for technical interviews through realistic AI-generated interview sessions.

The platform provides:

- 🤖 AI-powered interview questions
- 🎤 Voice-based interview experience
- 📝 Resume analysis
- 📊 Performance analytics
- 📈 Progress tracking
- 🏆 Leaderboards
- 💼 Company-wise interview preparation
